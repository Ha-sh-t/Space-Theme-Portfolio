# Space-Themed Portfolio Website

A modern, interactive portfolio website with a space theme, featuring smooth animations,and responsive design.

## 🌟 Features

- Interactive space-themed background
- Dynamic skill pyramid visualization
- Smooth animations and transitions
- Responsive design for all devices
- Dark mode optimized
- Particle effects and 3D elements

## 🛠️ Technologies Used

- **React.js** - UI library for building the interface
- **TypeScript** - For type-safe code
- **Tailwind CSS** - For styling and responsive design
- **Framer Motion** - For smooth animations and transitions
- **Three.js** - For 3D elements and space effects

### Development Tools

- **Git** - Version control
- **GitHub** - Code hosting and collaboration
- **Vite** - Build tool and development server

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Lakshit-003/portfolio.git
   ```

2. Install dependencies:

   ```bash
   cd portfolio
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
